# National Action Plan

Clickable prototype of Beyond Zero Emissions' National Action Plan: the
regional assessment criteria, the methodology behind each indicator, and the
per-region scores.

Published at <https://www.nationalactionplan.org.au>, behind a shared password
while the assessment content is being settled.

Plain static HTML, CSS and JavaScript. No framework, no bundler, no build step
for the site. See `CLAUDE.md` for the file map and the house rules, and
`deploy/build.mjs` for how the public site is assembled.

```
npm run dev     # http://localhost:5173, with the design-review overlay
```
